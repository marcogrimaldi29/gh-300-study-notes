GitHub Copilot in the IDE

Supported IDEs

GitHub Copilot works across a wide range of editors. Feature availability may vary — VS Code typically receives new features first.

IDE / EditorNotes

Visual Studio 2022 (17.8+)Includes comment suggestions; uses #solution chat variable to reference entire solution

Enabling Copilot in the IDE

Prerequisites

  • An active GitHub Copilot subscription (Free, Pro, Pro+, Max, Business, or Enterprise)
  • The GitHub Copilot extension installed from your IDE's marketplace
  • Authentication with your GitHub account inside the extension
  • For Business / Enterprise: organization admin must enable Copilot and assign a seat to the user
  • For Free plan: limited access with 50 premium requests/month included

Enable / Disable Granularity (VS Code)

  • Click the Copilot status icon in the bottom status bar → Enable or Disable
  • When disabling, VS Code asks whether to disable globally or just for the current file's language
  • Per-language control also available under Settings → Extensions → GitHub Copilot → Editor: Enable Auto Completions
  • You can enable inline suggestions for some languages while disabling them for others (e.g., disable for Markdown, keep enabled for Python)
ⓘ Copilot Free Plan

As of late 2024 GitHub offers a free tier of Copilot with limited features. Students, educators, and verified open-source maintainers may qualify for complimentary access to higher tiers. Always check the plans page for current eligibility.

Inline Suggestions & Keyboard Shortcuts

Inline suggestions appear as gray "ghost text" as you type. They are the most fundamental form of Copilot interaction.

Ghost Text Behavior

  • Suggestions appear automatically after a brief pause while typing
  • Triggered by: writing code, writing comments, starting a new function, or naming a variable
  • Multiple candidate suggestions exist — you can cycle through them
  • If you receive no or limited suggestions, duplication detection may be enabled — this is a common troubleshooting point

Keyboard Shortcuts Reference

Note: Xcode handles full suggestion acceptance via modifier keys rather than Tab. Line-by-line acceptance requires custom shortcut configuration in most editors.

⚠ Exam Tip — Shortcuts

Memorise the cycling shortcuts (Alt+] / Alt+[) and the accept shortcut (Tab). Know that opening the multiple suggestions panel is done with Ctrl+Enter on Windows. The "word-by-word" accept shortcut (Control+→) is also frequently tested.

Copilot Chat: Commands, Participants & Variables

Copilot Chat provides a conversational interface accessible from the IDE side panel, inline within the editor, and on GitHub.com. Reference: Asking Copilot questions in your IDE.

Slash Commands (type / to see full list)

CommandPurpose

/fixSuggest a fix for a bug or error in selected code
/test (or /tests)Generate unit tests for selected code
/docGenerate documentation/comments for selected code
/optimizeSuggest performance improvements

ParticipantAvailable inPurpose

Image Attachments

  • Copilot Chat supports attaching images to prompts: JPEG, PNG, GIF, WEBP
  • Useful for describing UI mockups, diagrams, or error screenshots

Model Selection

  • Users can switch the AI model Copilot uses for chat responses
  • Available models depend on the plan (see Capabilities & Policies page for plan details)
  • VS Code also supports model selection for inline (ghost text) suggestions

Plan Mode

Plan Mode lets Copilot create a detailed implementation plan before executing any changes. This is distinct from Agent Mode (autonomous execution).

  • Copilot analyses the task and produces a step-by-step plan
  • The plan shows which files will be created, edited, or deleted
  • You review and approve the plan before any code changes are made
  • After approval, you can switch to Agent Mode or Edit Mode to execute
  • Best for complex, multi-file work where you want full visibility upfront
⚠ Exam Tip — Three Modes

Know the distinction: Plan Mode = plan first, no auto-execution. Edit Mode = you pick files, Copilot edits with your approval per step. Agent Mode = fully autonomous, Copilot decides which files to touch and can run terminal commands. The exam tests which mode to use for a given scenario.

Smart Actions

  • Appear as a sparkle ✨ icon in the editor margin or on selected code
  • Provide context-sensitive Copilot actions without opening the chat panel
  • Examples: fix this, explain selection, generate docs, review selection
  • Available in VS Code and JetBrains IDEs

File & Repository Exclusions in the IDE

Exclusions are configured at the org/repo level in GitHub settings. The IDE enforces them locally.

  • Excluded files: Copilot does not offer inline suggestions when editing them
  • Excluded files: their content is not sent as context to the model
  • Changes to exclusion rules take up to 30 minutes to propagate to IDE clients
  • To force a refresh in VS Code: Command Palette → Developer: Reload Window
  • To force a refresh in JetBrains / Visual Studio: close and reopen the IDE
  • Important caveat: Copilot CLI, Copilot cloud agent, and Agent Mode do not support content exclusion

Command Palette

The Command Palette gives quick access to Copilot functions without memorising shortcuts.

  1. Open it in VS Code: Ctrl+Shift+P (Windows/Linux) or Cmd+Shift+P (Mac)
  2. Type Copilot to filter available commands
  3. Select actions like Explain This, Generate Unit Tests, or Developer: Reload Window

Troubleshooting in the IDE

  • Log files: Command Palette → Developer: Open Log File or Developer: Open Extensions Logs Folder
  • Electron/process-level logs: when nothing useful is in the regular logs, use Help → Toggle Developer Tools
  • Network/firewall/proxy issues: open the Command Palette and run GitHub Copilot: Collect Diagnostics — this opens a new editor with connection diagnostics you can inspect or share with support
  • Common cause of "no suggestions": content exclusion match, duplication detection, disabled-for-this-language setting, or an authentication/network failure

GitHub Copilot CLI

CLI Overview: Old Extension vs. New Agentic CLI

This is a frequently confused topic — there have been two different CLI tools with similar names. Know the distinction.

Old gh copilot extension (retired)New GitHub Copilot CLI (current)
StatusRetiredCurrent, actively developed
Installgh extension install github/gh-copilotnpm install -g @github/copilot (or winget/brew/curl)
Invocationgh copilot suggest / gh copilot explaincopilot (bare command)
CapabilitySuggests/explains a single shell commandFull agentic AI in the terminal — can write/debug code, run multi-step tasks, interact with GitHub.com
CategoryGitHub CLI extensionStandalone agent tool (same family as Agent Mode / cloud agent)
⚠ Exam Tip — Don't Conflate the Two

If a question describes a tool that only suggests/explains a single shell command, that's the retired extension. If it describes an agent that can write code, debug, create PRs, and run multi-step tasks from the terminal, that's the current GitHub Copilot CLI.

Installation & Authentication

Install Commands by Platform

PlatformCommand
npm (all platforms)npm install -g @github/copilot — requires Node.js 22+
Windowswinget install GitHub.Copilot
macOS / Linuxbrew install --cask copilot-cli
macOS / Linux (script)curl -fsSL https://gh.io/copilot-install | bash

Windows additionally requires PowerShell v6+. Requires an active Copilot subscription on all platforms.

Authentication

  • On first launch inside a session, run the /login slash command and follow the prompts
  • Alternative: a fine-grained Personal Access Token with "Copilot Requests" permission, set via an environment variable
  • Token environment variable precedence order: COPILOT_GITHUB_TOKEN → GH_TOKEN → GITHUB_TOKEN
  • Exam trap: the "Copilot Requests" permission is only available on user-owned fine-grained PATs — an organization-owned token cannot be used to authenticate the CLI

Interactive vs. Programmatic Mode

Interactive Mode

  • Start a conversation by running copilot in your project directory
  • You're prompted to trust the folder before Copilot can act on it
  • Two submodes:
    • Default ask/execute mode — converse and approve actions as you go
    • Plan Mode — toggle with Shift+Tab; Copilot analyzes the request, asks clarifying questions, and builds a structured plan before writing any code
  • Auto-compaction: conversation history is automatically compacted once it reaches 95% of the context window

Programmatic Mode

  • Pass a single prompt directly: copilot -p "your prompt" (or --prompt)
  • Completes the task and exits automatically — no interactive back-and-forth
  • Designed for scripts and CI/automation pipelines

Security: Trusted Directories & Tool Approval

  • Trusted directories: you explicitly designate which directories Copilot CLI may access and modify
  • Tool approval: by default, any command that modifies or executes files requires manual approval at each step
  • Approval flags: --allow-tool, --deny-tool, --allow-all-tools
  • Caution: --allow-all-tools grants Copilot "the same access as you do to files on your computer" with no per-action approval — use only in trusted, sandboxed contexts
  • Supports both local and cloud-based sandbox environments for isolated execution
  • Customizable via custom instructions, MCP servers, custom agents, hooks, skills, and persistent memory
  • Model configuration: choose GitHub-hosted models, or configure custom providers (OpenAI-compatible, Azure, Anthropic, local Ollama) via environment variables
⚠ Exam Tip — Tool Approval Is a Safeguard

The manual tool-approval system (and trusted directories) exists specifically so an autonomous terminal agent doesn't make unreviewed changes to your filesystem. Expect a question framing --allow-all-tools as the highest-risk configuration option.

Legacy Commands: suggest & explain

Retained here because the exam may still reference this pattern as the historical baseline for "Copilot in the command line."

CommandPurposeExample
gh copilot suggest Generate a shell command from a natural language description gh copilot suggest "list all git branches sorted by last commit"
gh copilot explain Explain what a command does, including flags gh copilot explain "git rebase -i HEAD~3"

After a suggest response, interactive options included:

  • Run this command — execute directly
  • Copy to clipboard — paste into your shell
  • Revise the command — refine with follow-up prompt
  • Explain this command — get an explanation before running

Suggestion Types (three categories)

TypeDescription
Generic shell commandStandard shell commands (ls, grep, find, awk, curl, etc.)
gh commandGitHub CLI-specific commands and workflows
git commandGit version control operations
💡 Study Tip — CLI Commands

Know that suggest/explain belong to the retired extension, while copilot (interactive or with -p) is the current agentic CLI. Know the three legacy suggestion types and the four legacy interactive options — both remain testable as historical/conceptual baseline.
